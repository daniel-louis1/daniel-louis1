## 📌 Featured Projects

### 🏀 [NBA Win Probability Dashboard](https://github.com/daniel-louis1/nba-win-probability)
Real-time NBA win probability tracker powered by a PyTorch neural network trained on 2.6M plays across 4 seasons (74% accuracy). Live predictions update every 5 seconds during games and stream to a dark, Kalshi-inspired Flask dashboard.

`Python` `PyTorch` `Flask` `nba_api` `Chart.js`

### 🏎️ [F1 Race Prediction](https://github.com/daniel-louis1/f1-race-prediction)
CMSC320 group project predicting Formula 1 race outcomes using a Random Forest classifier (74% accuracy). Covers full data science pipeline — EDA, feature engineering, hypothesis testing, and model evaluation.

`Python` `scikit-learn` `pandas` `matplotlib`
